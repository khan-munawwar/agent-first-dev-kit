# Agent-First Development Kit

A versioned, tool-agnostic framework that sets up software projects for AI
coding agents from day one. Context, decisions, specs, testing, CI/CD, and UI
rules that work across Claude Code, Codex, Cursor, and Gemini CLI.

## Status

Early work in progress. The first version is being extracted from real client
projects.
