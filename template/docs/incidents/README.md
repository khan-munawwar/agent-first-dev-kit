# Incidents

A blameless write-up (postmortem) for every problem with real impact: an
outage, data loss, a security finding, a broken release, or a bug that came
back. Copy `_template.md` to `YYYY-MM-DD-short-name.md`.

Triage:
- Minor bug: one line in `ISSUES.md`.
- Real impact: an incident write-up here.
- A lesson that must never be forgotten: also one line in "Critical
  invariants" in `AGENTS.md`, linking back here.
