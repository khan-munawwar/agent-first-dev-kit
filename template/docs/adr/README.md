# Architecture Decision Records

One file per decision with lasting effect: stack, data model, integration
pattern, hosting, security model, a rule that changes how code is written.

- Copy `0000-template.md` to `NNNN-short-title.md`. Numbers are never reused.
- An accepted ADR is never edited. To change a decision, write a new ADR that
  supersedes it, and set the old one's status to "Superseded by NNNN".
- Decisions found inside plans, meetings or chats become ADRs, so nobody has
  to re-argue them.
- The pre-commit reviewer treats code that contradicts an accepted ADR as a
  blocking finding.
