# ISSUES

Known bugs, tech debt and sharp edges. One line per item. IDs are never reused.
A bug that happened twice also becomes a line in "Critical invariants" in
`AGENTS.md`. A bug with real impact also gets an incident write-up in
`incidents/`.

Format: `ISS-### | severity (high, med, low) | area | symptom -> cause -> fix or workaround | state`
States: open, fixed (not verified), verified.
